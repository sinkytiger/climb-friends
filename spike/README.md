# 스파이크 테스트: 오픈채팅방 캘린더가 API로 보이는가?

카카오 톡캘린더 REST API로 **오픈채팅방에 등록한 일정을 읽어올 수 있는지** 확인하는 최소 테스트입니다.

## 0. 준비물
- Python 3.x (설치 확인 완료: 3.11.9)
- 오픈채팅방 **방장 본인의 카카오 계정**

## 1. 카카오 개발자 콘솔 설정 (약 10분)

> 콘솔 UI가 개편되어 메뉴 위치가 사람마다 다를 수 있습니다.
> 아래는 새 UI 기준이며, 메뉴명이 없으면 옛 경로를 참고하세요.

1. https://developers.kakao.com 접속 → 카카오 계정 로그인
2. [내 애플리케이션] → [애플리케이션 추가] → 아무 이름으로 생성 (예: `climbing-dash`)
3. 생성한 앱 선택 → **REST API 키** 복사
   - 새 UI: [앱 설정 > 플랫폼 키] 에 있는 32자리 REST API 키
   - 옛 UI: [앱 설정 > 요약정보]
   - ⚠️ Admin Key(64자리) 아님! REST API 키는 32자리 영숫자
4. 이 폴더의 **`.env`** 파일을 메모장으로 열어 아래처럼 붙여넣고 저장
   ```
   KAKAO_REST_API_KEY=복사한_REST_API키
   ```
   - `config.json` 은 예비용이므로 그냥 두면 됩니다 (.env 가 우선)
5. 카카오 로그인 활성화
   - [제품 설정 > 카카오 로그인] → **활성화 ON**
6. Redirect URI 등록 (`http://localhost:8080/oauth`)
   - 새 UI: [앱 설정 > 플랫폼 키] → REST API 키 옆 [설정] → "카카오 로그인 리다이렉트 URI"에 등록
   - 옛 UI: [제품 설정 > 카카오 로그인] 페이지 아래 "Redirect URI 등록"
   - ⚠️ "계정 상태 변경 웹훅" 메뉴과 다릅니다! 웹훅은 HTTPS 공개 주소가 필요하지만 우리와 무관
7. 동의항목 활성화
   - [제품 설정 > 카카오 로그인 > 동의항목] → **톡캘린더** 찾아 ON
   - "사이트 도메인/웹 도메인" 등록은 불필요 (HTTPS만 허용된다는 안내는 그쪽 얘기)

## 2. 실행 순서

| 순서 | 실행 | 하는 일 |
|---|---|---|
| 1 | `1_카카오로그인.bat` 더블클릭 | 브라우저 로그인 → `tokens.json` 생성 |
| 2 | `2_캘린더목록.bat` 더블클릭 | 내 캘린더 전체 목록 출력 |
| 3 | (스마트폰) 오픈채팅방 ☰ > 캘린더에서 **테스트 일정 1건 등록** | 예: "클라이밍 테스트" 내일 날짜로 |
| 4 | `3_일정조회.bat` 더블클릭 | 캘린더별 일정 요약 출력 |

> 콘솔(cmd 창)은 닫지 말고 결과를 끝까지 확인할 것.

## 3. 판정 기준

- **성공**: 3번 결과에서 오픈채팅방 이름의 캘린더에 "클라이밍 테스트" 일정이 보임
  → 기획안 그대로 진행 (백엔드 동기화 엔진 + 대시보드 구축)
- **실패**: 어떤 캘린더에도 해당 일정이 안 보임
  → 플랜 B 설계 (관리자가 대시보드에서 직접 일정 등록하는 폼 등)

## 문제 해결

| 증상 | 해결 |
|---|---|
| `invalid_client` | config.json 의 REST API 키 오타 확인 |
| `invalid_grant` | 인가 코드 만료. `1_카카오로그인.bat` 재실행 |
| `-402 insufficient scopes` | 동의항목에서 톡캘린더 미활성화. 콘솔 [카카오 로그인 > 동의항목]에서 톡캘린더 ON 후 1번 재실행 |
| `KOE009` | Redirect URI 불일치. 콘솔 등록값과 config.json 비교 |
| `포트 8080 사용 중` | 다른 프로그램 종료 후 재실행 |
| 브라우저가 안 열림 | 콘솔에 출력된 URL을 직접 복사해서 접속 |
| 401 오류 반복 | `tokens.json` 삭제 후 1번부터 재실행 |

## 보안 주의

`tokens.json` 과 `.env` 는 본인 계정의 권한 토큰/키입니다.
**절대 카톡/깃허브/블로그 등에 공유하거나 업로드하지 마세요.**
